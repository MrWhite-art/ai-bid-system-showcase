# 低保真线框（10 页）

AI 标书系统低保真线框，共 10 页。每页均为独立 HTML，可直接双击打开（无需构建与服务端）；公共样式复用 `shell.css`（侧边栏、顶栏、占位块等），各页局部样式写在各自 `<style>` 中。

## 页面清单

| 编号 | 文件 | 页面 | 一句话说明 |
| ---- | ---- | ---- | ---- |
| 01 | 01-login.html | 登录 | 系统登录入口，演示点击「进入系统」进入驾驶舱。 |
| 02 | 02-dashboard.html | 驾驶舱 | 工作台首页：在投项目、待评分标书等概览卡片与最近项目列表。 |
| 03 | 03-tenders.html | 投标项目 | 投标项目列表与「新建投标项目」弹窗占位。 |
| 04 | 04-parse.html | 标书解析 | 解析招标文件，展示评分标准表格与原文溯源浮层。 |
| 05 | 05-outline.html | 写作大纲 | 章节大纲树形占位与覆盖缺口提示。 |
| 06 | 06-writing.html | 写作工作台 | 大纲导航、编辑器、评分点与知识库参考四区布局。 |
| 07 | 07-matrix.html | 覆盖矩阵 | 评分点与响应内容对照表，标注已覆盖/待覆盖状态。 |
| 08 | 08-quote.html | 报价 | 成本拆分表、报价汇总卡与报价占比条（灰条占位）。 |
| 09 | 09-review.html | 审校 | 四类问题筛选标签、问题列表（类型徽标 + 定位按钮）与审校总结卡。 |
| 10 | 10-export.html | 导出 | 导出设置开关、导出进度条与完成卡片（Word/PDF 下载占位）。 |

## 导航关系

- 主线流程：登录（01）→ 驾驶舱（02）→ 招标文件（投标项目 03）→ 标书解析（04）→ 写作大纲（05）→ 写作工作台（06）→ 覆盖矩阵（07）→ 报价（08）→ 审校（09）→ 导出（10）。
- 写作、矩阵、报价、审校、导出等页面可经侧边栏直达；各页侧边栏当前项高亮（`is-on`）。
- 导出页（10）底部「回到驾驶舱」链接到 02-dashboard.html，形成流程闭环。

## 使用说明

- 每页可直接双击打开，页面间通过侧边栏与流程按钮互链。
- 视觉采用灰阶（slate 系）占位风格，绿色状态点为例外；具体视觉决策留给 Figma 高保真。
